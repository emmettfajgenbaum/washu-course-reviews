# docs

Reference material for this repo. Two folders, one rule each.

- **`docs/`** — live. True right now. Safe to read and act on.
- **`docs/archive/`** — finished, superseded, or abandoned. Kept for the reasoning, not the conclusions.
  **Never cite anything in `archive/` as current.**

This is where the extra markdown that accumulates over time goes, so it stops piling up at the repo root
or leaking into `claude-home/memory/`. The pool in `claude-home/memory/` is only for facts about **Emmett**
that no repo would hold; anything about a project belongs here, next to the code, where whoever changes the
code will see it.

Move a file into `archive/` the moment its conclusions stop being true or its plan is done.
